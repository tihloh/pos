# Receipt Printer Setup

Open:

**More → Receipt printer**

## Bluetooth ESC/POS

1. Pair the thermal printer in Android settings first.
2. Open Receipt printer settings.
3. Select **Bluetooth**.
4. Refresh paired devices.
5. Select the printer.
6. Tap **Test print**.
7. Save.

Classic Bluetooth SPP ESC/POS printers are supported.

## Network / Wi-Fi ESC/POS

1. Select **Network / Wi-Fi**.
2. Enter the printer IP/hostname.
3. Enter the TCP port.

A common ESC/POS raw TCP port is:

`9100`

4. Tap **Test print**.
5. Save.

## USB

Direct USB printer support is not currently implemented.
