# Privacy and Security

## Local-first storage

Operational POS data is stored locally on the Android device using Room.

## App lock

The app supports PIN and biometric/device-credential protection.

## Customer information

Only collect customer information that is actually needed for the business purpose.

## PhilSys

For PhilID/ePhilID-assisted registration:

- customer consent is requested before scanning
- raw QR payload is not retained
- PCN is not retained
- QR signature is not retained
- imported data is reviewed before use
- structure detection is not presented as cryptographic verification

## Source code

The application source repository is private.

This public repository contains product documentation and signed APK releases only.
