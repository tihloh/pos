# Sales

The Sales screen supports:

- Today
- 7 Days
- 30 Days
- All

You can search by:

- receipt number
- customer name

## Summary

Sales shows:

- total sales
- transaction count
- payments received
- outstanding balance when Account Payable sales exist

## Transaction details

Tap a transaction to view:

- line items
- quantities
- totals
- paid amount
- change or remaining balance
- payment mode
- payment reference when available

Receipts can be reprinted from the transaction details.
