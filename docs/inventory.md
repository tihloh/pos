# Inventory

Inventory uses a transaction ledger.

The simplified inventory view shows:

- Beginning
- Added
- Removed
- Sold
- Current stock

Tap an inventory card to open the stock adjustment dialog.

## Typical adjustments

Use inventory adjustments for situations such as:

- receiving stock
- damaged/lost stock
- physical-count corrections
- opening inventory

Sales automatically create negative stock transactions for inventory-enabled products.
